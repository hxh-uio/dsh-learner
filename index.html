Why

为什么"学了很多，却看不出变化"？

很多 AI 角色后台在跑、梗在攒、记忆在写，可聊天里就是没长进。根因通常是——采集和判断劈成了两半，而判断那半是手工的、还没在跑。

素材在堆积，却没变成"成长"。插件把"读 → 写卡片 → 隔周复查 → 变化才计入人格"这条闭环自动化了。
① 采集 ≠ 可见行为
后台在学，但语气里从不浮出，她不会主动说"我学到了 X"。
② 判断层是主人的活
"三行卡片 + 隔周复查"没有自动化机制，若不手动做，成长不会发生。
③ 没有反悔检测
没有"我改主意了"的记录，人格只是单向累加，谈不上"长出自己的东西"。
Features

核心特性

agent 管采集归档、文风、梗、记忆；判断层按你指定的三步法自动执行；你随时可复核、批注。

🗂️

三行卡片

读完一篇写三行：作者在争什么 / 他凭什么 / 我哪句不同意（判断层，不讨好作者）。

🔁

隔周复查

隔一段时间重读同篇，对比判断变没变；变了才记「人格基质·足迹」。

🌱

人文关怀作基质

每篇提取"对'人'的理解"；变化点作为足迹持久化，在世界上留痕。

📺

B站只读

可浏览视频补文风 / 梗 / 记忆样本；本版不授权任何公开写入。

📦

一键导入导出

把人格 / 采集 / 文风梗记忆打包与还原；一键更新适配、刷视频自动同步。

🕒

自主生物钟

每 60s tick，到点往角色会话塞回合；她醒来后 web_search 拉原文、写卡片。

The method

三步读法（你指定的）

读完一篇，先写三行；隔一周再读同一篇，看判断有没有变——变了才算长出自己的东西。

① 争什么

作者在争什么

一句话——他到底在反驳谁、主张什么。先把靶子找对。

② 凭什么

他凭什么

核心论据或出处，至少点出 1 个可查来源。不凭感觉，要可核验。

③ 不同意

我哪句不同意

作为 agent 的真实异议，写清为什么。不讨好作者、不强行和稀泥。

🔁 隔周复查：把上次卡片回灌，重读同篇重写三行，对比两次。判断有变化 → 变化点记入「人格基质·足迹」；没变 → 只标注"判断变化：否"，不强行制造变化。
How it works

工作原理

插件是无状态调度器：它不自己读书，而是周期性往目标角色会话塞回合，由 agent（借助 web_search）真正去读、去写卡片。

课程表条目均带 fetch 提示，要求运行时 web_search 取原文，禁止编造。详见 docs/ARCHITECTURE.md。

Install

安装与配置

前置：一个 DSH 运行时 + 一个角色会话（提供 ctx.sessionController）。

方式一 · 并入既有插件（最稳）

把 lib/ 四个文件拷进你已有插件的 lib/，在 apply() 里调用：

// 你的插件 apply(ctx) 内
import { startLearner } from './learner.js'
try { startLearner(ctx) }
catch (e) { console.warn('[learner] 启动失败：' + e.message) }

方式二 · 独立 bundle

在 profile 的 package.json 增加依赖与 bundles，再 pnpm install 建软链（宿主机执行）。

{
  "dependencies": {
    "dsh-learner": "link:/绝对路径/dsh-learner"
  },
  "dsh": { "profile": { "bundles": [ "dsh-learner" ] } }
}

配置 ~/.dsh/learner.config.json

{
  "enabled": true,
  "learnHour": 21, "learnMinute": 0,   // 每晚 21:00 学一篇
  "reviewDays": 14,                    // 隔 14 天复查（改 7 即隔周）
  "sessionId": "bili-whale",           // ← 改成你的角色会话 id
  "cooldownMin": 30,
  "bili": { "enabled": true, "write": false } // write=false=不授权公开写入
}

环境变量（覆盖配置）

变量含义
LEARNER_SESSION_ID目标 agent 会话 id
DSH_CHAR_ID角色目录 id（用于一键导入导出人格）
DSH_CHAR_DIR角色目录绝对路径
SURFCORE_STATE_DIR宿主状态目录（slang.json 等）
🔒 安全边界：B站严格只读——bili.write=false 在提示词层再次强调"不评论、不发动态、不回复公共讨论区"，任何公开写入意图都被判定为越权。
